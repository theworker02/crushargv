# crushargv

Crush CSV/TSV argv tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/crushargv/

## Install / run

```bash
git clone https://github.com/theworker02/crushargv.git
cd crushargv
node src/cli.js
node --test
```
